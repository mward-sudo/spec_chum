Spec Chum

Play ZX Spectrum software on a modern computer.

A faithful Spectrum emulator for macOS, Windows, and Linux — download a release and load the games and programs you remember.

Download How to use

Made for playing

Load software, pick a Spectrum model, and play on the computer you already use.

  • Games and programs Run classic ZX Spectrum software from downloads and archives you already have.
  • Tapes that load Open TAP and TZX files; speed up loading when you want, or keep the authentic tape feel.
  • The machines you remember 48K, 128K, +2 / +2A, +3, and Timex models in one emulator.
  • macOS, Windows, and Linux Release packages include the redistributable Spectrum ROMs — open the download and go.

Get it for your computer

Grab the latest release for your platform — installers and portable archives are on GitHub.

  • macOS Native SpecChumMac app: unzip the .dmg.zip, open the disk image, drag to Applications.
  • Windows Use the installer (*-setup.exe) or the portable .zip.
  • Linux .deb, AppImage, or .tar.gz — whichever fits how you install software.

Choosing an emulator?

If you care how faithfully Spectrum software runs, Spec Chum aims for careful timing — not just a quick window that boots.

  • Faithful behaviour Picky titles get careful Z80 and display timing so games behave the way you expect.
  • Same product, several hosts Native macOS app plus cross-platform builds — features stay aligned across the computers you use.

For curious developers

Optional detail if you like looking under the hood — player downloads above are enough to start.

  • Accuracy-minded core From-scratch Z80 and ULA work with a serious timing focus; deep notes live in the developer docs.
  • Cross-platform hosts egui app, native macOS shell, and optional Windows / Linux native shells over a shared host API.
  • Local debug HTTP API Scripted control and framebuffer export on localhost for automation and inspection — see the Agent Debug API docs.
