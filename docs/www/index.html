Spec Chum

A hardware-accurate ZX Spectrum emulator.

Built from scratch in Rust — cycle-accurate Z80 and ULA timing, with release builds for macOS, Windows, and Linux.

Download Docs GitHub

What you get

Present capabilities for players — detail lives in the docs.

  • Accurate core Cycle-accurate Z80 and ULA (contention, floating bus, border).
  • Many models 48K, 128K, +2 / +2A, +3, Timex TC2048 / TS2068, and more.
  • Tape & media TAP/TZX paths with flash-load and turbo EAR options that still load correctly.
  • Release packages Redistributable Spectrum ROMs bundled in GitHub Release archives.

Platforms

Pick a release artifact for your machine, or build from source.

  • macOS — SpecChumMac Native SwiftUI app in the release .dmg.zip (unzip, open the disk image, drag to Applications).
  • Windows Installer (*-setup.exe) or portable .zip; egui is the release UI.
  • Linux .deb, AppImage, or .tar.gz; egui is the release primary (optional GTK shell available from source).
